# Windows 本地长期运行

双击项目根目录的 `启动.cmd`，安装或启动 Windows 计划任务 `AH-Taoli-Monitor`。
网页地址是 http://127.0.0.1:8510 。任务在当前用户登录 Windows 后自动运行，
不弹出命令行窗口；网页进程退出后约 5 秒自动重启，托管进程异常退出后由 Windows 重启。
任务无运行时长限制，也不会因为切换电池供电而停止。

- `停止.cmd`：停止当前网页服务；下次登录 Windows 时仍会自动启动。
- `关闭自动启动.cmd`：停止网页并关闭自动启动；再次运行 `启动.cmd` 可重新启用。
- 日志：`.runtime/monitor.log`，每份最多约 10 MB，保留 3 份历史日志。
- 任务状态：Windows「任务计划程序」中查看 `AH-Taoli-Monitor`。

这是登录后运行的本地服务。电脑关机、睡眠或用户注销时网页不可用；
锁屏和关闭浏览器不影响服务。富途 OpenD 仍需单独启动、登录并保持连接。
该地址只允许本机访问。如果要全天候或远程使用，需要另行配置服务器部署。
